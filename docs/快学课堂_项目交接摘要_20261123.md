# 快学课堂项目交接摘要

2026-11-23

## 项目目标

在创易灵动主站体系内交付完整的快学课堂桌面客户端：

- 主站账号、购课权益、积分钱包和课程后台。
- 学院画布完整编辑、素材、生成、保存和恢复。
- 灵动 VibeCoding 完整 Agent、Skill、MCP、Browser Use、工程和作品预览。
- 本机优先、云端回退的混合运行模式。

## 当前架构

### 本机模式

- Electron 主进程启动本地 `course-runtime.mjs`。
- ZCode CLI、Agent、会话、任务、文件服务、Skill 和 MCP 在学员电脑执行。
- Browser Use 使用本机 Chrome 或 Edge。
- 本机运行器只监听 `127.0.0.1` 随机端口，使用随机 RPC 令牌。
- 工程保存在 `app.getPath('userData')/vibe-projects/{user/course/version hash}/workspace`。
- AI 推理不在本机执行，仍通过主站短期模型令牌调用模型网关。

### 云端回退

- 本机授权或运行器不可用时，自动使用现有云端工作区。
- 云端容器包含 Chromium、Browser Use、Node REPL、Office/PDF 工具和中文依赖。
- 云端工程仍按用户、课程和版本持久化。

### 运行版本

- 当前统一基线为 ZCode `0.16.9`，与源码服务端和 Web 工作台一致。
- 不要单独升级 CLI 到 `0.17`。如需升级，必须同时升级服务端协议、Web 工作台和运行资源。

## 主站已确认的接口

### 本机模型授权

```http
POST /api/v1/course-runs/local-runtime
```

返回 `runId`、`userId`、`presets` 和短期 `modelGateway`：

```json
{
  "baseUrl": "https://...",
  "token": "...",
  "modelIds": ["完整模型 ID"],
  "expiresAt": 1795446000000
}
```

模型授权必须绑定用户、课程、版本和运行，不能下发主站长期密钥。

### 本机工程快照

已确认采用整目录 ZIP：

```http
POST /api/v1/course-runs/local-snapshot
Content-Type: application/zip
X-Kuaixue-Run-Id: <runId>
X-Kuaixue-Base-Revision: <revision>
X-Kuaixue-Snapshot-SHA256: <sha256>

GET /api/v1/course-runs/local-snapshot?runId=<runId>
```

- 压缩后上限建议 64 MiB，解压后 256 MiB，文件数 20,000。
- 拒绝路径穿越、绝对路径、符号链接、硬链接、加密包和重复文件名。
- 下载返回 ZIP，并带 `ETag`、revision、SHA256 和 capturedAt。
- 公共路径继续由快学课程服务承接，快学校验会话、运行和权益，再调用主站内部能力。
