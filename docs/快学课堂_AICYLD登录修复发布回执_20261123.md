# AICYLD 快学课堂登录修复发布回执

2026-11-23 23:39（北京时间）

## 根因

`aicyld-kuaixue.service` 的生产 systemd 配置只允许访问回环网络：

```text
IPAddressDeny=0.0.0.0/0 ::/0
IPAddressAllow=127.0.0.0/8 ::1/128
```

课程服务在微信确认后却通过公网 `https://aicyld.com.cn/api/auth/me` 自调用主站；公网域名解析到 `8.134.120.22`，该请求被服务沙箱阻断并超时。扫码和微信回调本身成功，失败发生在账号换票阶段。

## 修复

账号、钱包、流水和内部接口统一使用：

```env
KUAIXUE_INTERNAL_ORIGIN=http://127.0.0.1:3001
```

公网主站地址只用于浏览器 Origin、微信登录和用户可见跳转。

- 修复提交：`8a49770 fix: route kuaixue server reads through loopback`
- 当前源码 HEAD：`76df693`
- 自动测试：`107/107` 通过
- 临时授权流程换票已快速访问回环 `/api/auth/me`；假令牌返回预期的 `401 主站登录态无效`
- 修复前同一探测返回 `The operation was aborted due to timeout`
