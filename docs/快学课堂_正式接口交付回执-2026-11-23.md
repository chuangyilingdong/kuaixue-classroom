## 先验目录与登录

`GET /api/v1/catalog/courses` 公网实测返回 `200` 和以下正文。客户端应展示空目录。主站运营发布第一门获准展示的正式课后，回传 `courseId`、`versionId`、价格和工作区。此前的隔离联调课仅供测试记录使用。

```json
{"data":{"items":[],"page":{"limit":20,"total":0,"nextCursor":null}}}
```

有课后调用 `GET /api/v1/catalog/courses/{courseId}?versionId={versionId}`，核对 `data.course` 的 `id`、`versionId`、`unlockPricePoints` 和 `permittedDeliveryModes`。

学员在授权页选择主站登录，登录后返回授权页，点击“同意并返回快学课堂”。桌面端发送 `client_id`、`redirect_uri`、`response_type=code`、随机 `state`、`code_challenge`、`code_challenge_method=S256`。收到回调后校验完整地址及原 `state`，再换码。授权码有效 90 秒，只能使用一次。

| 客户端请求 | 成功响应及失效处理 |
| --- | --- |
| `POST /api/v1/desktop/session`，JSON `{"code":"<一次性码>","verifier":"<原始PKCE校验值>","redirectUri":"https://aicyld.com.cn/kuaixue/desktop/callback","clientId":"kuaixue-desktop"}` | `200 {"data":{"authenticated":true}}`。服务端会话最长 8 小时，返回 `Set-Cookie: kuaixue_session=<省略>; Path=/api/v1; HttpOnly; Secure; SameSite=None`。参数无效为 `400 INVALID_CALLBACK`，重复兑换为 `401 LOGIN_FAILED`。 |
| `GET /api/v1/me` | `200 {"data":{"user":{"id":"user-example","name":"示例学员"},"points":300,"entitlements":[]}}`。`points` 是本人余额。缺少会话返回 `401 SESSION_REQUIRED`，携带已失效的会话返回 `401 SESSION_EXPIRED`。 |
| `GET /api/v1/me/entitlements` | 未购时 `200 {"data":{"entitlements":[]}}`。权益项格式为 `{"courseId":"course-example","versionId":"version-example","status":"active"}`，撤权后为 `revoked`。当余额查询失败时仍可单独读取权益。 |
| `POST /api/v1/desktop/logout` | `200 {"data":{"authenticated":false}}`。服务端撤销快学会话并清 Cookie。 |

## 购课、查单与流水

以下成功订单和金额均为脱敏契约示例。正式交易验收待单独确认。客户端使用课程服务，付款人由会话确定，定价取自正式课程版本，钱包扣款由服务端执行。

| 请求 | 响应及处理 |
| --- | --- |
| `POST /api/v1/course-purchases`，JSON `{"courseId":"course-example","versionId":"version-example"}` | 当前开关关闭。未登录返回 `401 {"error":{"code":"SESSION_REQUIRED"}}`。已登录的关闭分支返回 `423 {"error":{"code":"PURCHASES_DISABLED","message":"正式购课暂未开放"}}`。 |
| 开启后首次购买或同账号同版本原样重试 | 两次均应得到同一 `orderId`，示例为 `200 {"data":{"orderId":"order-example","courseId":"course-example","versionId":"version-example","status":"confirmed"}}`。双工作区共用一单。余额不足返回 `402 COURSE_ACTION_FAILED`。超时后有单号先查原单，没有单号时重试同一课程版本，等确认后再开放权益。 |
| `GET /api/v1/wallet/orders/order-example` | 本人已确认订单示例为 `200 {"data":{"orderId":"order-example","userId":"user-example","courseId":"course-example","versionId":"version-example","points":100,"status":"confirmed","transactionId":"kx-order-example"}}`。`pending` 表示待确认，`revoked` 表示权益已撤销，查无本人订单返回 `404 ORDER_NOT_FOUND`。 |
| `GET /api/v1/wallet/ledger?limit=50&offset=0` | 空页返回 `200 {"items":[],"total":0}`。`items` 和 `total` 位于顶层，默认每页 50 条，最多 200 条。购课明细用 `sourceOrderId` 关联订单，`amount` 表示积分变动。同一消费跨积分池可能拆成多条明细，按订单号及扣分合计对账。 |
| 退款或冲正 | 正式退款接口待开放。售后由主站钱包团队按原 `orderId` 核对。真实购课前先确认回退方式。 |

## 验证记录与分工

- **生产公网**已核对学员入口、后台课程页面、空课程目录、授权页和未登录访问控制。已核对目录响应允许桌面来源携带会话。正式登录、运营发课、扣分与工作区进入仍待对应账号验收。
- **本机隔离验证**使用发布版服务、模拟主站身份与钱包。换码、授权码限用一次、本人资料/权益/流水、购课关闭时的 `423` 和退出后旧会话失效均已通过。
- **主站运营**负责发布可展示的正式课程并回传编号。**快学客户端**可立即核对空目录与授权入口，由账号所有人完成正式登录。账号对接归主站账户团队，扣款、查单及售后归主站钱包团队。
- **快学与学院、灵动运行方**负责学院画布和 VibeCoding 的运行接入。购后按课程版本核对允许的工作区。VibeCoding 正式运行源和运行票据适配待交付。灵动 Code 支持按 token 扣分，快学付费生成适配待接通。
- **真实交易验收**需单独确认账号、课程版本、扣分上限和回退安排，再核对重复购买只扣一次、已购可进、未购不可进。本轮真实积分扣款、退款及付费模型调用均为零。
