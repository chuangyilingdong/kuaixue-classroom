## 一、已确认的业务规则

用户已确认：

> 购买课程一次，后续版本免费升级。

本轮按以下语义实现：

1. 权益属于 `courseId`，不再要求当前 `versionId` 存在独立订单。
2. 同一课程任一版本存在已确认订单，后续发布版本自动拥有访问权。
3. 打开未单独购买的后续版本时不会创建新订单，也不会扣积分。
4. 历史版本订单继续保留，作为购买、退款和审计记录。
5. 同一课程有多个历史已确认订单时，撤销其中一个订单不会自动撤销其他有效购买。
6. 只有该课程的所有已确认订单都被撤销后，课程访问权才失效。
7. Dnins 在新版本产生的 1 积分订单未退款；退款属于钱包流水变更，本轮没有用户明确指令，因此没有执行。

### 权益数据流

```text
课程版本发布
  → 用户打开课程
  → 按 courseId 查找任一 confirmed 订单
      ├─ 存在：继承课程权益，零扣款、零新订单
      └─ 不存在：按当前版本价格创建 pending 订单并调用钱包
```

实现位置：

- `apps/api/course-platform.mjs`
- `src/data/account.js`
- `src/data/learningGrants.js`

回归场景：

- 首版购买后发布新版，不产生第二次钱包扣款；
- 新版可直接进入工作区；
- 继承版本保存的作品可出现在“我的作品”；
- 课程详情、账户权益和工作区校验使用一致的课程级判断；
- 历史订单与撤销语义继续保留。

## 二、Electron Browser/webview 侧栏

### 为什么没有把 webview 放进 ZCode iframe

实测 Electron 41 只在顶层文档注册 `<webview>`。在跨域、sandbox iframe 中：

```text
customElements.get('webview') === undefined
```

因此 iframe 里的 ZCode 组件即使开启 `supportsEmbeddedBrowser=true`，也无法创建 guest。

当前实现：

```text
ZCode 工作台（跨域 iframe）
  → 只发送“切换浏览器 / 打开 URL / 新标签页”消息
快学主窗口（Electron 顶层）
  → 创建真正的 <webview>
  → 维护标签页、地址栏、前进、后退、刷新、系统浏览器打开
  → 处理网页弹窗并回到内部标签页
```

### 已实现能力

- 原生 `<webview>` 页面合成，网页内容位于 Electron guest，不是普通 iframe；
- 右侧可调整宽度分栏；
- 多标签页、关闭标签页、新建标签页；
- 地址栏、后退、前进、刷新；
- 页面标题、加载状态、加载错误和重试；
- ZCode 工作台可请求打开指定网页；
- ZCode 工作台请求可自动打开课程壳层 Browser 侧栏；
- 网页弹窗由主进程拦截，安全 URL 回到内部新标签页；
- “在系统浏览器打开”入口。

### 安全边界

- Browser guest 使用独立 `persist:zcode-embedded-browser` 分区；
- `contextIsolation=true`；
- `nodeIntegration=false`；
- `sandbox=true`；
- 删除 guest preload；
- 禁止页面权限请求；
- 仅允许匿名 HTTP/HTTPS 与 `about:blank`；
- 禁止 `file:`、`javascript:`、`data:` 和未知自定义协议；
- 页面弹窗只能回到内部 Browser 标签页或明确 HTTP/HTTPS 地址；
- 工作台 iframe 不能直接调用桌面文件、Node 或任意 IPC。

- 模型选择；
- 思考强度滑杆；
- Ctrl+M / Ctrl+T 快捷键。

课程版只向原版组件提供当前课程的模型目录、思考档位回调、模型锁定规则和 Vibe 用量门禁，没有改写其菜单布局、搜索、选中态或滑杆交互。

### P1：Browser Agent 真正连接可见 IAB

当前 Human Browser 与 Agent Browser 是两套后端：

```text
用户侧：Electron 顶层 webview
Agent 侧：managed headless CDP
```

下一步需要把 browser-use 的 IAB bridge 接到主进程 guest：

- attach/detach CDP；
- BrowserViewReady / Operation / Visibility 事件；
- 标签归属、关闭和恢复；
- 截图合成表面；
- 操作状态与错误回传。

### P1：原版内容插件验收

至少在课程模型中验证：

- PDF 读取与生成；
- DOCX 读取与编辑；
- PPTX 读取与生成；
- XLSX 读取、公式和图表；
- image-search。

### P2：按课程价值开放

不建议直接恢复原版完整设置页。可做课程专用设置：

- 浏览器缓存清理；
- 下载与站点数据；
- 工作区打开位置；
- 主题；
- 模型说明和课程额度；
- 使用帮助。
