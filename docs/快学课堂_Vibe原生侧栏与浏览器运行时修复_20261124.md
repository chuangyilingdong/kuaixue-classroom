# 快学课堂 Vibe 原生侧栏、启动加载与浏览器运行时修复

日期：2026-11-24

## 结论

- Vibe 工作区冷启动不再显示无反馈黑屏，改为品牌加载层，并至少保持到工作区壳层稳定。
- 课程壳层单独创建的右侧“作品预览”第三栏已删除。
- HTML 产物点击后使用 ZCode 原生 code-viewer 侧栏打开，内嵌沙箱 iframe 渲染页面。
- 正式包补入 `playwright-core` 和 `@napi-rs/keyring`，Browser Use 的 CDP 后端可以加载。
- 使用安装后 runtime 的浏览器 canary 已通过。

## 黑屏根因

工作台是大体积 React 应用，首次打开要加载约 5.8 MB 主 bundle，并恢复本地 profile、
项目与任务索引。旧入口在 React 根挂载后没有持续加载层，所以页面壳已接管但会话内容尚未
恢复时只显示纯深色背景。

现在入口会在 iframe 中显示：

```text
正在打开课程工作区…
正在恢复课堂项目与对话
```

检测到 composer 后还会等待 1.5 秒再移除，避免加载层刚消失又露出空白内容区。

## 原生产物侧栏

删除：

- `kuaixue-open-html-preview` 外层消息；
- `openCourseHtmlPreview` 平台桥；
- 课程壳层右侧额外预览 iframe；
- 顶部“预览作品”和注入的“HTML 预览”按钮。

保留：

- ZCode 原生产物卡片/文件链接；
- 原生 code-viewer side pane；
- HTML 源文件在 code-viewer 中以沙箱 iframe 渲染；
- 普通代码、Markdown、图片和 Office 文件继续走原有 ZCode 预览。

## Browser Use 运行时

旧安装包只有：

```text
vibe-local-runtime/packages/browser-use-plugin
```

缺少：

```text
vibe-local-runtime/node_modules/playwright-core
vibe-local-runtime/node_modules/@napi-rs/keyring
```

因此 agent 能看到 Browser Use 工具，但初始化托管浏览器时得到 `backend_unavailable`。

现已：

- 在 electron-builder `extraResources` 中显式打包两个运行时目录；
- 设置 `NODE_PATH` 指向随包 `vibe-local-runtime/node_modules`；
- 使用安装后 runtime 执行 Browser Use canary。

canary 结果：

```json
{
  "browserBackend": "cdp",
  "title": "Browser Canary",
  "body": "浏览器可用",
  "screenshot": true,
  "result": "BROWSER_CANARY_OK"
}
```
