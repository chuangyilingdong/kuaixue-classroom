本清单供快学、主站运营和运行服务负责人执行。接口字段以同目录《快学课堂_正式接口交付回执-2026-11-23.md》为准。目标是：新学员能从主站找到并安装 Windows 客户端，使用本人账号按课程标价购买，进入承诺的工作区并找回作品；故障时能停止销售、查账和处理售后。放出链接不等于完成发布。

## 放行与回退

- **可以先展示，不能先卖。** 空目录和授权页通过仅说明客户端连上正式站。未验双区不宣传双区，未验付费生成不承诺生成；若要只上画布课程，由运营另发明确只含画布且能独立完成的版本，不缩水已购版本。
- **转为公开付费前**，负责人对同一发布版本留存四类证据：正式课与标价、已授权交易与权益对账、工作区作品重开、可回退的安装包及服务版本。明确谁有权关购课、撤下载、处理异常订单。
- **出故障先止损。** 账务异常由主站关闭新购并核对原订单；创作故障暂停受影响课程新售或模型调用；包故障暂停分发/更新，切回已验版本。保护既有权益和作品，不用回滚数据库覆盖新订单，不让学员重买。客服按订单号登记影响，必要时由钱包侧走批准的退回流程。
- **重新开放**须由相应负责人修复、逐单对账、确认已有作品可恢复，先对小范围用户复验，再由业务负责人放量。

**眼下只需运营做一件事：** 发布第一门获准展示的正式课并回传四项数据；购课继续关闭。本人登录、工作区正式运行接入、安装包准备可以并行，不需要等真实扣费才开始。
