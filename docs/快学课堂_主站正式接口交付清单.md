# 快学课堂接入创易灵动｜主站正式接口交付清单

**请主站直接按此交付：已有正式接口就给地址和脱敏样例；没有的，按下列最小约定补建。** 不需要再准备测试账号、发测试课或给账号加分。此清单描述快学客户端需要的契约，不表示这些接口已经在生产上线。若主站内部路径或字段不同，提供真实契约即可，快学做适配，不用重做一套账号和钱包。

VibeCoding 运行票据的装配代码、接口样例及上线分工见[主站接入说明](./快学课堂_VibeCoding运行票据接入.md)。

## 一、请主站交付的四项

| 事项 | 已有则直接复用 | 没有则如何建立 |
| --- | --- | --- |
| **1. 主站入口与发课后台** | 唯一的课程运营入口是创易灵动主站 `https://admin.aicyld.com.cn/` 的「快学课堂 → 课程管理」。运营在这里创建课程、设置积分价、选择学院画布 / VibeCoding / 两者，按版本编排画布素材和框体、设置 VibeCoding 预设提示词，并发布新版或下架。主站前台另设面向学员的快学课堂入口，不改 AIGC 教程。 | 若正式后台尚无此菜单，请主站把快学提供的课程管理页面组件（`integrations/main-site-admin`）接进现有正式运营后台，沿用主站运营登录、权限、CSRF 和审计，并连接同一份正式课程数据。**不另建快学运营后台，也不在学员客户端设置课程。** 客户端读取已发布版本，购后按权益开放对应工作区。 |
| **2. 正式主站账号授权** | 用现有主站登录页与真实用户 ID，登记正式桌面应用，交付授权页 URL、公开 `clientId`、精确回调 URI、会话期限及退出方式。 | 增加桌面授权码流程（PKCE S256）。用户只在主站输入凭据；授权后返回 `code` 和原 `state`，服务端核对一次性短期授权码、校验值、客户端及回调。课程 API 建立可撤销的快学会话；不要把主站长期令牌、密码或 `client_secret` 发给桌面端。 |
| **3. 正式账户与积分钱包** | 提供本人资料、余额、流水、按业务订单号查交易、按订单号扣积分的正式能力。快学当前服务端适配读 `GET /api/auth/me`（`id,username`）和 `GET /api/points/wallet`（`total`）；如主站格式不同，请给映射。 | 若钱包目前只能读余额，补**仅服务端可调**的购课扣款/查单接口，以 `orderId` 幂等；余额更新与流水写入在同一事务内。接入主站现有退款/冲正；若无，则补按原交易幂等退回和退款结果查询/通知。具体约定见第三节。不要将通用扣积分接口开放给客户端。 |
| **4. 正式域名及服务接入** | 给学员课程 API 的正式 HTTPS 根地址、授权域名、运营后台地址、服务间鉴权方式和负责人。域名可以不同。 | 若目前只有后台域名，可在选定的正式 API 网关挂载/反代快学课程服务。`/api/v1` 由客户端追加；所给 API 根地址不要再带 `/api`。课程 API 精确允许桌面来源 `kuaixue://classroom` 携带会话，支持预检；后台管理接口不向桌面端开放。不要放行 `*` 或 `Origin: null` 来解决授权问题。 |

## 二、桌面端与后台所用的接口（快学已有代码，不要求主站重复开发）

| 使用方 | 正式路由或能力 | 接入约定 |
| --- | --- | --- |
| 主站浏览器授权页 | `GET <主站正式授权页>`；回到 `<正式课程服务源>/kuaixue/desktop/callback` | 客户端发送 `client_id, redirect_uri, response_type=code, state, code_challenge, code_challenge_method=S256`。授权页使用主站正常登录与表单安全机制。若需跳其他登录域名，请连同域名交付，以便快学核对桌面导航白名单。 |
| 桌面会话 | `POST /api/v1/desktop/session`、`POST /api/v1/desktop/logout` | 换码 JSON：`{code,verifier,redirectUri,clientId}`；成功返回 `data.authenticated=true`，并由课程 API 设置 `kuaixue_session`（`Secure; HttpOnly; SameSite=None`）。退出须服务端撤销并清 Cookie。快学提供路由，主站接入授权码兑换、会话识别与撤销。 |
| 学员账户 | `GET /api/v1/me`、`GET /api/v1/me/entitlements` | `data` 含 `user:{id,name}`、`points`、`entitlements:[{courseId,versionId,status}]`；主站是账号/余额来源，快学按已确认订单生成权益。只读本人；钱包异常不能把已购权益清空。 |
| 运营发课 | `GET /api/admin/kuaixue/courses`；`POST /api/admin/kuaixue/courses/publish`、`POST /api/admin/kuaixue/courses/hide` | 发布回执 `data.id`、`data.versionId`。改版保留课程 ID、生成新版本；下架停止新购，不撤销已购旧版本。 |
| 课程列表与详情 | `GET /api/v1/catalog/courses`；`GET /api/v1/catalog/courses/{courseId}?versionId={versionId}` | 分别返回 `data.items` 和 `data.course`，含 `id,versionId,title,unlockPricePoints,permittedDeliveryModes`。可公开展示的课程介绍与购后创作内容分开。 |
| 学员购课 | `POST /api/v1/course-purchases` | 客户端只传 `{courseId,versionId}`，不能传价格、付款人或权益。服务端按会话和发布版本定价；成功返回 `data:{orderId,courseId,versionId,status:"confirmed"}`。双工作区一笔订单。 |
| 本人查单与流水 | `GET /api/v1/wallet/orders/{orderId}`、`GET /api/v1/wallet/ledger` | 主站提供正式路由或等效钱包接口供快学封装。订单可查交易号、状态、积分数；流水含订单号、交易号、积分变动和时间，只返回本人记录，说明分页规则。 |
| 购后创作 | `POST /api/v1/course-runs/open`、`POST /api/v1/course-runs/save`、`POST /api/v1/course-runs/works` | 快学服务负责开工作区、保存和我的作品。打开传 `{courseId,versionId,mode}`，每次验证本人权益和版本允许的模式；未登录 `401`、未购或未获该模式 `403`。主站不需要另做一套工作区接口。 |

## 三、钱包缺接口时，按这个约定补建

下表是**主站钱包与快学服务之间**的契约，路径由主站定；若同服务部署，可用受控服务方法，不需要新增公网扣款地址。

| 能力 | 最少入参 | 结果与规则 |
| --- | --- | --- |
| 扣款或返回原结果 | `orderId,userId,courseId,versionId,points` | 确认后返回 `orderId,userId,points,transactionId,status=confirmed`。同账号同版本复用原购课订单；并发、重试或服务重启只能有一笔扣款。同 `orderId` 不同付款人或金额应拒绝。余额不足不扣款（客户端 `402`）。 |
| 按订单号查交易 | `orderId`（受控服务身份；学员侧从会话确定本人） | 区分未找到、处理中、已确认、失败、已退款；交付状态值映射。超时先按**原订单**查，未知结果不发权益、不换新单扣款。已扣但未发权益须能补发。 |
| 退款/冲正及结果 | 唯一 `refundId`、原 `orderId`、原 `transactionId`、应退积分 | 首期按整笔购课退款；重复处理只退一次。主站返回退款状态和退款流水，通过签名通知或受鉴权查询给快学。快学复核后仅撤销对应课程版本权益；购课退款不混入模型消耗。退款暂未提供，请明示正式售后处理方式及负责人。 |

## 四、画布、VibeCoding 和模型结算：谁做什么

- **学院画布**由快学与学院项目对接。主站后台保存该版本的 `materialGroups`、`canvasSnapshot`；快学在客户端完整工作区展示、按用户及课程版本保存。保护素材的读取与生成由学院/快学对接，不让主站重写画布。
- **灵动 VibeCoding**由快学与灵动客户端项目对接。运营配置 `classroomConfig.vibeCoding.presetPrompts`；学员选择后只插入草稿，不自动发送。正式开放 VibeCoding 前，由快学/灵动交付正式 HTTPS 运行源及 `issueRuntimeTicket` 适配；如课程服务部署在主站，由主站运维装配该适配和受信服务连接。票据按用户、课程、版本、工作区和运行实例签发；没接通前不上架承诺该能力的付费课。
- **AI 用量与购课是两笔业务。** 主站如有可复用的灵动 Code 正式计费网关，请提供负责人、服务端鉴权、模型列表、计价规则、按任务查单及实际用量结算样例。画布图像/视频等不默认套用 token 计价。没有对应计费能力就先关闭该类付费生成，不阻塞账号、发课与购课接入。快学已有画布报价/确认入口 `POST /api/v1/generations/quote`、`POST /api/v1/generations/confirm`，不要求主站重建模型运行服务。

## 五、主站做好后，请一次性交付

1. **公开配置**：正式 `VITE_KUAIXUE_API_BASE_URL`（只填源）、`VITE_KUAIXUE_AUTHORIZE_URL`、`VITE_KUAIXUE_CLIENT_ID`、已登记的完整回调 URI。快学侧设置 `VITE_KUAIXUE_COURSE_SERVICE=1`；`VITE_KUAIXUE_VIBE_ORIGIN` 由快学向灵动运行方确认。
2. **后台与发课**：正式后台 `https://admin.aicyld.com.cn/` 的菜单位置、主站前台入口位置、一个获准核对的正式 `courseId/versionId`，注明课程价格和工作区。若无可展示的正式课程，请说明，不要把联调课程迁入正式目录。
3. **钱包与授权契约**：提供 OpenAPI **或**脱敏的请求/响应样例，覆盖换码、本人账户、扣款、重复请求、查单、流水、退款和失效状态。列明哪些已上线、哪些复用旧接口、哪些未交付，以及对接人。服务凭据由运维通过私密渠道或密钥管理系统配置，不发聊天、不进安装包。
4. **核对顺序**：快学拿到配置先只读核对正式目录、版本；经账号所有人授权核对登录与本人权益。**不自动扣真实积分、不自动退款或调用付费模型。** 如需正式交易验证，另行确认指定账号、课程、扣分上限及回退安排后再做。
