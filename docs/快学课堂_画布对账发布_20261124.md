# 快学课堂画布对账发布

2026-11-24

## 背景

快学课堂支持 `CANVAS` 和 `VIBECODING` 两种工作区，但后台“快学课堂对账”原先只查询
`operation='kuaixue.vibecoding'`。课程画布生成使用普通画布计费记录，因此没有进入课程维度对账，
会少算画布积分、上游成本和相关异常。

## 实现

新增“画布对账”页签，使用以下链路精确关联：

```text
kx_generation.id
  = canvas_billing_hold.taskId
kx_generation.run
  = kx_runs.id
kx_runs.version
  = kx_versions.version
```

这样可以只筛选快学课程画布任务，不把普通全站画布消费混入课程对账。

展示与核对内容：

- 用户、课程、课程版本、运行实例、节点
- 生成状态、模型、任务 ID
- 预扣、结算、退回和积分流水净扣
- 预估成本、实际上游成本和账单对账状态
- 画布净消耗、预扣及待对账汇总
- CSV 导出和异常清单筛选

异常规则：

- 课程画布任务缺少预扣记录
- 同一任务存在重复预扣
- 运行实例用户不一致
- 预扣记录运行 ID 与任务不一致
- 生成完成但结算未完成
- 生成失败但费用未退回
- 结算记录缺少积分流水
- 预扣记录与积分流水金额不一致
- 上游账单待处理或异常

`integrations/main-site-admin/mountCourses.mjs` 和
`integrations/main-site-admin/modelDirectory.mjs`。后台旧进程原本继续可用，但重启后会因缺少运行时依赖
进入重启循环。
