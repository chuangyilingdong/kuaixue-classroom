# 快学课堂桌面验收

启动 `release/classroom-workspace-preview/win-unpacked/快学课堂.exe`，进入「课程库 → 从故事分镜到互动网页」。新档案用 100 演示积分解锁一次；已在默认演示档案购买的版本不必重买。

- **学院画布**：打开即占满标题栏以下、导航栏右侧的空间。「故事分镜」是本版本配置的素材组；点击「镜头草稿」添加框体，再点「分镜起稿」选择要填入的框体。返回课程后重进仍保留自己的快照。
- **灵动 VibeCoding**：同一块空间显示原版工作台。点工作台左下「课堂提示词预设 → 互动故事页面」，关闭弹窗后能在小灵输入框看到文字，可以修改，不会自动发送。
- 快学不在工作区旁放通用步骤清单。「返回课程」会保存对应作品。演示不调用真实模型，也不使用主站积分。

`node scripts/workshop-smoke.cjs` 使用独立测试档案验证两个原生交互、窗口占用和购买结果。正式主站接口与字段见 `docs/快学课堂_主站正式接口交付清单.md`。
