# 快学课堂 Vibe 工程预览、工作区持久化与存储边界

## 结论

本轮修复了“任务结果里有 `index.html`，但课程外壳预览不到”的问题：

- ZCode 当前任务工程不再被课程壳固定为初次打开的隐藏目录。
- 工作台标题栏增加“HTML 预览”，点击后在课程右侧打开当前工程的 `index.html`。
- 点击任务正文中的 HTML 文件链接也会走同一课程侧栏预览。
- Vibe 使用次数移到模型栏“上下文”圆环左侧，不再覆盖模型按钮。
- ZCode profile 改为按“用户 + 课程 + 课程版本”持久保存；关闭时只清除短期模型凭据。

## 根因

用户在 ZCode 中通过“新项目”选择了外部目录：

```text
C:\Users\Administrator\Documents\新建文件夹 (2)
```

该目录中的 `index.html`、`styles.css`、`app.js` 均已生成。课程外壳仍读取：

```text
C:\Users\Administrator\AppData\Roaming\KuaixueClassroom\vibe-projects\测试一下-8d619911
```

因此不是 HTML 没有产出，而是 ZCode 与课程外壳持有不同的工作区根目录。

第二个问题是课程版原先为每次打开创建临时 ZCode profile，关闭后删除。工程文件仍在，
但任务、项目登记和 tab 索引会消失。现已改为持久 profile，首次升级会优先迁移包含项目
或任务索引的旧 profile。

## 工作区规则

Vibe 工作区按以下三元组隔离：

```text
userId + courseId + versionId
```

不同课程、不同课程版本或不同用户使用不同目录。首次进入时自动创建目录和
`index.html`。同一课程的后续运行复用该课程工作区。

工程根目录可以是：

- 自动目录：`%APPDATA%\KuaixueClassroom\vibe-projects\<课程名>-<hash>`
- 用户在原生目录选择器中指定的其他目录

## 存储边界

| 内容 | 当前存储位置 | 说明 |
| --- | --- | --- |
| Vibe 工程源码和作品文件 | 用户本机当前工程目录 | ZCode 直接读写 |
| Vibe 项目、任务和 tab 索引 | 本机 `vibe-profiles\<hash>\.zcode\v2` | 按课程版本持久保存 |
| Vibe 模型短期凭据 | 本机 profile，仅本次运行 | 关闭时清除，过期由主站控制 |
| Vibe 本次任务进程、终端、本地预览服务 | 用户本机 | 仅监听回环地址 |
| 画布编辑状态 | 首次保存前在应用内存 | 点击“保存”后写课程服务 |
| 画布版本、步骤进度、作品状态 | 课程服务 SQLite/`kx_runs` | 重新进入课程时恢复 |
| 画布上传的图片、音频、视频 | 课程服务素材目录和 `kx_assets` | 上传完成即写服务端 |
| 账号、课程权益、课程目录 | 主站和课程服务 | 客户端不自行判定 |
| Vibe 使用额度和扣次台账 | 主站 | 按 `(runId, queryId)` 一次用户回合计一次 |
| 模型接入、报价、预扣和结算 | 主站模型网关 | 客户端只持有短期授权 |
| AI 图片、视频、音频生成 | 服务端外部模型渠道 | RunningHub 等任务在服务端执行 |

当前 Vibe 代码文件不是自动上传到服务端。点击“保存”会校验本机 `index.html` 并更新课程
进度；整目录快照上传接口已经存在，但尚未接入普通“保存”按钮的自动备份流程。

画布则相反：编辑草稿在内存中，用户点击“保存”后画布快照写服务端；上传素材会立即写
服务端。

## HTML 预览链路

```text
ZCode 当前任务/项目
  -> 识别当前工作区目录
  -> 点击“HTML 预览”或任务中的 HTML 文件
  -> 向课程外壳发送 kuaixue-open-html-preview
  -> Electron 校验目录属于默认工程或原生选择器授权根目录
  -> 本地回环预览服务读取该目录中的 HTML 及其相对资源
  -> 右侧沙箱 iframe 渲染
```

预览服务不接受任意文件路径；HTML 必须位于当前工作区内，资源访问也限制在同一根目录。

## 已知边界

- 从旧临时 profile 迁移的历史任务可以恢复任务/项目索引，但旧对话内容可能因原 ZCode
  云端订阅身份不在课程 Web 适配层中而显示 `fault.subscription.contentRejected`；新任务在
  持久 profile 中继续执行。
- 当前 Vibe 整目录快照上传接口尚未接入普通保存和自动备份。
- 画布尚未实现本地离线草稿，关闭前未点击“保存”的内存修改会丢失。
