## 构建与发布状态

快学使用灵动原版 Web 工作台 `@zcode/ui` 和 RPC 工程服务。原生客户端的浏览器、随包技能和插件还需要课程运行端支持。原版安装目录与开发源码目录自带的资源不同，本次随包技能数量取自已安装的原版客户端。正式课程运行的 ZCode CLI 为 0.16.9，本机原版客户端为 0.17.0；两端版本和随包资源需要统一后再宣称完整移植。

候选网页构建在 `release/vibe-workbench-candidate/`，修复接在卡片现有的打开路径。测试使用隔离工程和本机运行服务，生产本轮模型调用为 0。仓库测试 71 项通过，其中 4 项覆盖 HTML 读取边界。

公网工作台与本地修复前的网页入口文件哈希不同。发布时需要在当前线上工作台基线上合入预览修复，保留已上线的聊天模型配置，再用原学员已有文件卡片复验。公开放量前还应分别验证实际子 Agent 任务、浏览器操作、插件加载、画布文件上传及真实生成后的保存重开。
