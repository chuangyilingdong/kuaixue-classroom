画布视频和动画节点由 `preload="none"` 改为 `preload="metadata"`。

原因：`preload="none"` 只画播放器控件，不加载首帧，视频节点静置时呈黑块。

### Vibe HTML 卡片与侧栏

已修正两个问题：

1. `index.html` 可能在前一轮写入，后续轮次再提及时被“本轮 fileChanges”门禁过滤；
2. HTML 侧栏此前使用 `srcDoc` + opaque-origin sandbox，在当前 Chromium 中会空白或退出渲染进程。

当前规则：

- 根目录 `index.html` 在任意已完成轮次被提及时可生成 HTML 卡片；
- 卡片仍会通过工作区文件服务校验文件真实存在；
- 点击卡片在 ZCode 原生 code-viewer 侧栏打开；
- HTML 使用 `blob:` URL；
- sandbox 保留 opaque origin，不加入 `allow-same-origin`。

注意：课程版不是原版 ZCode Electron Browser/webview 侧栏。课程工作台本身在 Web iframe 中，当前 `supportsEmbeddedBrowser=false`，所以使用原生 code-viewer 壳层中的安全 HTML iframe。两者功能验收通过，但宿主实现不同。
