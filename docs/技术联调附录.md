# 快学课堂技术联调附录

本附录供快学开发人员查阅。正式分工、接口和交付要求以同目录的《快学课堂_主站正式接口交付清单.md》为准。

## 主站后台与快学服务

- 管理页面传入 `createKuaixueAdminApi(主站的JSON请求函数)`。该函数须保留主站登录与 CSRF 头，HTTP 失败时抛错。将 `mountKuaixueCourses` 挂到主站 Express 应用的受保护路由，注入真实权限检查、CSRF 校验、操作者 ID 和快学课程服务。接口根为 `/api/admin/kuaixue/courses`。运营发布、改版、下架写入审计记录。
- `apps/api/course-platform.mjs` 提供课程服务。单节点联调使用独立 SQLite 文件。主站后台与学员 API 必须使用同一份课程数据。跨主机部署时由主站后台通过受信服务调用快学服务。
- 服务端配置 `KUAIXUE_COURSE_DB`、`KUAIXUE_MAIN_SITE_ORIGIN` 和 `KUAIXUE_ACCOUNT_PROVIDER`。提供方导出 `identity(session)`、`desktopAuth`、`debitOrLookup(order)`（工作区票据 `issueRuntimeTicket(context)` 由快学对接运行服务）。`desktopAuth` 指定 `clientId`、`redirectUri`、`revokeSession` 和 `exchange`。`revokeSession` 立即使旧快学会话失效。`exchange`校验并兑换主站授权码，再返回绑定账号且有过期时间的快学会话标识。积分接口按 `orderId` 查询或扣款，结果含 `orderId/userId/points/transactionId/status`。退款回调验签并核实后调用 `revoke(orderId, 原交易号)`。
- 联网桌面构建设置 `.env.example` 中的 `VITE_KUAIXUE_*` 参数，课程服务精确允许 `kuaixue://classroom`。默认桌面构建使用本机演示数据。学员 API 通过会话识别用户，购课请求只传课程与版本编号，价格由服务端读取。

## 工作区与模型计费（快学侧另行联调）

学院画布使用学院项目的素材组、提示词、生成框体和初始画布。快学侧与学院项目方确认受保护素材的读取授权、生成产物地址及有效期；与灵动 VibeCoding 项目方确认课程工程隔离、持久保存及运行授权。若主站有可复用的按量扣分接口，再共同核对计量和流水。以下是快学适配约定，不是主站第一轮的交付项。

- 在灵动运行域名 `/kuaixue/workbench/` 部署 `release/vibe-course-web/`，并挂载 `integrations/vibecoding/runtime-broker.mjs` 的换票和 WebSocket 路由。代理应允许快学窗口嵌入。`checkAccess` 可绑定快学服务的 `hasRuntimeAccess`，`courseWorkspaceDirectory(存储根目录, 快学服务)` 提供 `openWorkspace`，首次进入创建课程工程，重进保留文件改动。`scoped-socket.mjs` 提供 `acceptScopedSocket`。宿主通过 `resolveHost` 返回该学员本次课程专属的 RPC 服务地址及服务间令牌，各连接只访问指定课程工程，网关日志需屏蔽票据。启动票据 60 秒有效，连接票据 30 秒有效，均为单次使用。
- 启动 VibeCoding 服务前，调用 `provisionCourseProvider({profile,context,platform,gateway})`。`context` 含 `userId`、`courseId`、`versionId`、`runId` 和 `mode`。模型网关签发同一范围的短期 `token`，提供 `baseUrl`、`modelIds` 和毫秒时间戳 `expiresAt`。课程模型取发布版本与网关授权的交集。运行服务应只加载本课模型，禁用学员自配提供方。网关对每次请求复核模型、权益、授权额度和有效期，按任务号结算。正式运行服务需把学员工程、文件访问、终端和进程隔离到该学员的课程环境，回收租约时保留工程并清理凭据。
- `quoteGeneration(job)` 返回 `quoteId/points/expiresAt`，有效期用毫秒时间戳。`generateOrLookup(job, offer)` 必须以 `jobId` 幂等，按已确认报价控制扣费上限，从服务端选择模型。结算成功返回 `jobId/status=settled/transactionId/asset`，失败且已释放资金时返回 `jobId/status=released`，超时或待确认沿用原任务。两项适配就绪后，画布才开放对应模型的生成操作。

## 按工作区发布课程内容

学院画布使用 `materialGroups[].materials`：生成框体为 `GENERATION_BOX`（配置在 `snapshot.box`），提示词为 `PROMPT`（正文在 `snapshot.content`）；组和组内素材均按发布顺序展示。可导入 `canvasSnapshot` 作为首次起点，重进优先使用学员保存的快照。
VibeCoding 使用 `classroomConfig.vibeCoding.presetPrompts: [{title,text}]`。换票时按当前权益读取已购版本，返回 `presets`，经 `getPresets()` 给灵动原版弹窗。仅插入当前任务草稿，不自动发送。没有配置时不合成教学步骤。`steps` 只作可选详情页大纲。
