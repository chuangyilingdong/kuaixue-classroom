## 源码文件

生产启动入口为仓库根目录的 `formal-server.cjs`。从仓库生成交付目录时至少包含：

```text
formal-server.cjs
formal-provider.cjs
course-models.mjs
consent.html
apps/api/
shared/
integrations/vibecoding/main-site-tickets.mjs
integrations/vibecoding/runtime-broker.mjs
integrations/main-site-admin/mountCourses.mjs
integrations/main-site-admin/modelDirectory.mjs
```

`integrations/main-site-admin/` 同时是后台课程管理页的运行时依赖，不能只随管理端源码存在；`package:course-service` 会把它纳入固定发布清单并自动测试。

服务运行时还需要生产环境提供的课程库、票据库、素材目录、`kx-chat` Unix Socket 和主站回环 API。仓库不包含这些数据或密钥。

## 地址边界

```env
KUAIXUE_MAIN_SITE_ORIGIN=https://aicyld.com.cn
KUAIXUE_INTERNAL_ORIGIN=http://127.0.0.1:3001
KUAIXUE_PUBLIC_MAIN_ORIGIN=https://aicyld.com.cn
KUAIXUE_BIND_HOST=127.0.0.1
KUAIXUE_API_PORT=4188
```

- 浏览器登录页和微信回调使用公网 `KUAIXUE_PUBLIC_MAIN_ORIGIN` / `KUAIXUE_MAIN_SITE_ORIGIN`。
- 课程服务访问主站账号、钱包、流水和 `/internal/kuaixue/*` 时统一使用 `KUAIXUE_INTERNAL_ORIGIN`，因为生产服务仅允许访问回环地址。
- `/internal/*` 不允许从公网访问；错误地使用公网主站地址会由 Nginx 返回 `404`。
- `KUAIXUE_CLIENT_ID` 默认 `kuaixue-desktop`。
- `KUAIXUE_REDIRECT_URI` 默认 `https://aicyld.com.cn/kuaixue/desktop/callback`。

## 必需配置

密钥通过生产环境或受管环境文件注入，不进入源码、安装包或日志。

```env
KUAIXUE_MAIN_SITE_ORIGIN=https://aicyld.com.cn
KUAIXUE_INTERNAL_ORIGIN=http://127.0.0.1:3001
KUAIXUE_PUBLIC_MAIN_ORIGIN=https://aicyld.com.cn
KUAIXUE_CLIENT_ID=kuaixue-desktop
KUAIXUE_REDIRECT_URI=https://aicyld.com.cn/kuaixue/desktop/callback
KUAIXUE_SESSION_SECRET=<secret>
KUAIXUE_INTERNAL_SECRET=<shared-with-main-site>
KUAIXUE_WALLET_SECRET=<wallet-service-secret>
KUAIXUE_CANVAS_BILLING_SECRET=<same-as-main-site-canvas-billing-secret>
RUNNINGHUB_API_KEY=<secret>
RUNNINGHUB_AI_API_KEY=<secret>
KUAIXUE_COURSE_DB=/absolute/path/to/course.sqlite
KUAIXUE_RUNTIME_TICKET_DB=/absolute/path/to/runtime-tickets.sqlite
KUAIXUE_ASSET_ROOT=/absolute/path/to/kuaixue-assets
KUAIXUE_BIND_HOST=127.0.0.1
KUAIXUE_API_PORT=4188
KUAIXUE_PURCHASES_ENABLED=0
```

注意：

- `KUAIXUE_CANVAS_BILLING_SECRET` 必须与主站 `CANVAS_BILLING_SECRET` 一致。
- `KUAIXUE_WALLET_SECRET` 必须与主站钱包内部接口的鉴权密钥一致。
- 课程库、票据库和素材目录必须使用绝对路径。
- 所有密钥仅供服务进程读取，不得写入 `.env.official`、Electron `app.asar` 或客户端资源。

## 启动与检查

由生产进程管理器加载环境后运行：

```bash
node formal-server.cjs
```

启动后检查：

```bash
curl -fsS http://127.0.0.1:4188/healthz
curl -fsS https://aicyld.com.cn/api/v1/catalog/courses
```

匿名访问运行能力必须被拒绝：

```bash
curl -sS -o /dev/null -w '%{http_code}\n' \
  https://aicyld.com.cn/api/v1/course-runs/local-runtime
```

预期为 `401`。如果服务已运行但运行授权返回 `503`，先核对 `KUAIXUE_INTERNAL_ORIGIN`、内部密钥、`kx-chat` Socket 和数据库权限，不要改成公网 `/internal/*`。
