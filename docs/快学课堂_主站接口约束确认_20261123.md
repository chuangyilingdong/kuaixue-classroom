# 快学课堂主站接口约束确认

2026-11-23

| 主站约束 | 快学侧实现 |
| --- | --- |
| 桌面登录 `ui=kx-class-v1` | 桌面授权 URL 已固定携带。微信登录页已轮询授权结果。桌面回调即使返回 `204`，客户端也会直接按回调 URL 中的 `state/code` 完成换码，不依赖回调页 HTML。 |
| 课程详情字段 | 归一化保留 `classroomConfig`、`permittedDeliveryModes`、`vibeModelIds`、封面、时长和学习目标。 |
| 版本模型快照 | 本机和云端 Provider 只使用课程运行授权返回的、该版本的模型 ID，不读取后续新增模型。 |
| 模型前台显示名称 | 课程数据同时返回 `vibeModelIds`（完整 ID）和 `vibeModelLabels`（完整 ID 到“模型家族·前台显示”名称的映射）。客户端只展示映射名称，完整 ID 仅用于授权和运行。 |
| 积分流水来源 | 客户端不按 `source` 合并或推断交易，只展示主站返回的余额和权益。来源字段由主站账本保留。 |
| 流水关联字段 | 客户端不读取 `billingHoldId`，以主站正式账本的 `pointsledger.refId = canvas_billing_hold.id` 为准。 |
| 幂等与旧版本 | 购课重试继续使用同一订单结果。权益按 `courseId + versionId` 保存，历史版本不因课程发布新版本而删除。 |
| 媒体 URL | 课程媒体只接受 HTTPS 或主站相对路径。`javascript:`、`data:`、`blob:`、协议相对地址、带账号密码的 URL 和反斜杠相对路径会被拒绝。 |
| Range | 课程素材和工程预览的媒体响应均支持单段 `Range`，返回 `206`、`Content-Range` 和 `Accept-Ranges: bytes`。 |
| 退款 | 主站当前返回 `REFUND_NOT_CONFIGURED`，客户端不展示“已支持退款”的对外承诺。 |

## 当前课程版本

```text
courseId=0477cad8-48ff-4737-b06f-a814220ed466
versionId=464e75e8-784f-4c50-8edb-456cd90d54c4
```

主站课程详情接口必须在该版本中返回 `vibeModelIds` 的 13 个 RunningHub 模型快照。客户端不使用实时模型目录替换该列表。
