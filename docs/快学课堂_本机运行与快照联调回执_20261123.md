### 短期模型授权

公开入口：

```http
POST /api/v1/course-runs/local-runtime
```

课程服务先校验 `kuaixue_session`、运行归属、已购版本和 `VIBECODING` 模式，再调用：

```http
POST /internal/kuaixue/runtime-grant
x-kuaixue-internal-secret: <KUAIXUE_INTERNAL_SECRET>
```

请求中的 `userId`、`courseId`、`versionId`、`runId`、`mode` 和完整 `modelIds` 都来自服务端已校验的运行版本，不接受客户端提交。返回授权还必须与当前课程版本的完整模型清单一致，否则按不可用处理并回退云端。

### 整目录快照

公开入口：

```http
POST /api/v1/course-runs/local-snapshot
GET  /api/v1/course-runs/local-snapshot?runId=<runId>
```

上传时客户端发送 `application/zip`，快学服务校验会话、运行、权益、版本和模式后，转发到主站：

```http
POST /internal/kuaixue/snapshots
GET  /internal/kuaixue/snapshots?userId=...&courseId=...&versionId=...&runId=...
```

实现行为：

- ZIP 压缩后上限 64 MiB。
- 公开路由校验 ZIP SHA-256 后调用内部接口。
- `409 SNAPSHOT_CONFLICT` 和 `currentRevision` 原样返回给客户端。
- 同一 SHA-256 重试保持幂等。
- 下载转发 `ETag`、`X-Kuaixue-Revision`、`X-Kuaixue-Snapshot-SHA256`、`X-Kuaixue-Captured-At`。
- CORS 预检和实际响应均允许并暴露快照所需请求头/响应头。

## 桌面客户端

- Electron 主进程扫描完整工作区并生成 ZIP，不把单个 `index.html` 当工程快照。
- 打包拒绝符号链接、特殊文件和越界路径，并执行 20,000 文件、256 MiB 解压上限。
- 云端快照下载后先核对 revision、时间、Content-Type 和 SHA-256，再解压到临时目录。
- 恢复时先完成解压，再替换本机工作区；已有工作区会移动到 `snapshot-backups`，替换失败时回滚。
- 每个用户/课程/版本在自己的工程目录外保存 `local-snapshot.json`，记录云端 revision、摘要和时间，避免换目录或重开后误覆盖。
- 学员界面保持单一工作台，不展示本机/云端、切换或手动同步概念。

## 文档能力

- ZCode 自带 Excel、Word、PPT、PDF 官方插件。
- 本机运行时优先复用 ZCode 或随包 Python 环境，保留 Excel、Word、PPT 生成能力。
- 本机已用 ZCode 的 Python 环境实际生成并校验 `.xlsx` 文件，确认 Excel 输出不依赖 LibreOffice。
- 不再按课程预设关键词判断文档课程，也不因缺少 LibreOffice 把整门课程切到云端。
- LibreOffice 仅影响 Office 转 PDF、公式重算和部分渲染检查等特定操作。
