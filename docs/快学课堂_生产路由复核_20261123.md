# 快学课堂生产路由复核

2026-11-23 23:38（北京时间）

## 复核结果

| 请求 | 实测 | 预期 |
| --- | --- | --- |
| `GET /api/v1/catalog/courses` | `200` | `200` |
| `POST /api/v1/course-runs/local-runtime` | `401` | 未登录 `401` |
| `GET /api/v1/course-runs/local-snapshot?runId=fixture` | `401` | 未登录 `401` |
| `POST /api/v1/course-runs/local-snapshot` | `401` | 未登录 `401` |
| `POST /api/v1/course-assets` | `404` | 未登录 `401` |

`course-assets` 的响应正文为：

```json
{"error":"接口不存在"}
```

响应由主站 Express 返回，而源码里的课程服务会在鉴权前识别该路径。因此需要生产运维核对 Nginx 的 `/api/v1/course-assets` 转发或当前课程服务进程是否实际加载了本轮 `apps/api/server.mjs`。

## 影响

- 本机运行授权、快照和目录接口不受影响。
- 画布素材上传会失败，因而不能据此宣称完整画布生产验收通过。
- 客户端源码与 107 项自动测试已包含该路由；本次复核未修改生产。

## 下一步

1. 由生产运维确认 `POST /api/v1/course-assets` 被转发到课程服务。
2. 匿名复核应返回 `401 SESSION_REQUIRED`，而不是主站 `404 接口不存在`。
3. 正式账号批准后再验证真实素材上传；真实 `gpt-image-2.5` 生成仍需单独费用批准。
