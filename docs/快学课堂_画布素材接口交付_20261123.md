# 快学课堂画布素材接口交付

本文是快学客户端已经接入的正式接口 contract。主站实现可用对象存储代替本地文件保存，但请求、鉴权和响应语义必须一致。

## 上传

`POST /api/v1/course-assets`

请求使用原始文件字节，不使用 Base64 或 JSON：

```http
Origin: kuaixue://classroom
Cookie: kuaixue_session=...
Content-Type: image/png
X-Kuaixue-Run-Id: 8c61c48d-...
X-Kuaixue-File-Name: %E7%94%BB%E9%9D%A2.png
X-Kuaixue-Asset-Kind: image
```

- `Content-Type` 必须是允许的图片、视频或音频 MIME。
- `X-Kuaixue-Run-Id` 必须是当前登录用户已购版本打开的画布运行编号。
- `X-Kuaixue-File-Name` 使用 `encodeURIComponent`。
- `X-Kuaixue-Asset-Kind` 只能是 `image`、`video`、`audio`。
- 默认单文件上限 50 MiB。主站可以调低，但超限必须返回 `413`。

成功返回：

```json
{
  "data": {
    "id": "asset-uuid",
    "name": "画面.png",
    "mime": "image/png",
    "size": 184320,
    "kind": "image",
    "assetUrl": "https://aicyld.com.cn/api/v1/course-assets/asset-uuid",
    "previewUrl": "https://aicyld.com.cn/api/v1/course-assets/asset-uuid"
  }
}
```

`assetUrl` 和 `previewUrl` 必须是客户端可持久化并在重启后继续访问的 HTTPS 地址。

## 读取

`GET /api/v1/course-assets/{id}`

- 必须校验当前登录会话是该素材所属用户。
- 返回原始媒体字节、原始 MIME、`Cache-Control: private, max-age=31536000, immutable` 和 `X-Content-Type-Options: nosniff`。
- 不得接受客户端传入文件系统路径。
- 不允许 SVG、HTML 或可执行脚本 MIME 作为画布素材。

## 允许 MIME

| 类型 | MIME |
| --- | --- |
| 图片 | `image/jpeg`, `image/png`, `image/webp`, `image/gif` |
| 视频 | `video/mp4`, `video/webm`, `video/quicktime` |
| 音频 | `audio/mpeg`, `audio/mp4`, `audio/aac`, `audio/ogg`, `audio/wav`, `audio/webm` |

## 失败语义

| 状态 | 含义 |
| --- | --- |
| `401` | 未登录或会话过期 |
| `403` | 运行实例不属于当前用户、未购或课程权益已撤销 |
| `413` | 超过单文件限制 |
| `415` | MIME 不在允许清单 |
| `503` | 对象存储或素材服务不可用 |

## 持久化与回收

- 素材至少保存：素材 ID、用户 ID、运行 ID、课程、版本、文件名、MIME、字节数、对象 key、创建时间。
- 画布快照只保存 `assetUrl`、`previewUrl` 和 `fileAssetId`，不保存服务器本地路径。
- 删除课程授权后立即拒绝新上传；是否立即删除素材由主站的留存策略决定，但不能继续对撤销用户提供读取。
- 需要备份素材对象和元数据。对象 key 使用内容哈希或不可猜测 ID。
