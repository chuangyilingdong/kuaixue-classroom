## 二、Electron Browser/webview 侧栏已完成

### 架构原因

实测 Electron 41 只在顶层文档注册 `<webview>`。在跨域、sandbox iframe 中：

```text
customElements.get('webview') === undefined
```

因此不能在 ZCode iframe 内直接实现原版 webview 侧栏。

当前架构：

```text
ZCode iframe
  → postMessage 请求切换浏览器或打开 URL
Electron 顶层 CourseRun
  → 创建真正的 <webview>
  → 管理多标签、地址栏、导航、分栏和弹窗
```

### 已完成能力

- Electron 顶层原生 `<webview>`；
- 右侧可调整宽度分栏；
- 多标签页、新建和关闭；
- 地址栏、后退、前进、刷新；
- 页面标题、加载状态、错误和重试；
- ZCode iframe 可请求打开指定网页；
- 网页弹窗由主进程收回内部新标签；
- 在系统浏览器打开；
- Browser 只由 ZCode 工作台请求自动打开，不额外增加课程顶栏按钮。

关键文件：

### 安全边界

- 独立 `persist:zcode-embedded-browser` 分区；
- guest `sandbox=true`；
- `contextIsolation=true`；
- `nodeIntegration=false`；
- 删除 guest preload；
- 拒绝页面权限请求；
- 仅允许匿名 HTTP/HTTPS 与 `about:blank`；
- 禁止 `file:`、`javascript:`、`data:`；
- iframe 不能直接获得桌面文件、Node 或任意 IPC。
