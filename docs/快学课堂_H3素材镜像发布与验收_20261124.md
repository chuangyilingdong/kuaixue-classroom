# 快学课堂 H3 素材镜像发布与验收

2026-11-24 12:54（北京时间）

## 结论

0120 发布后的 H3 失败不是计费或余额问题。失败任务均已预扣 42 并及时全额退回。
实际执行链路有两个上游契约问题：

1. 课程适配器向 `rh-minimax-h3-multi` 发送了 `generateAudio: false`。已成功跑过的
   H3 通道不发送该字段，只发送 `prompt / ratio / resolution / duration / imageUrls`。
2. 课程站内参考图只被转换成短期签名公网 URL，没有先镜像到 RunningHub。
   当前生成前先从课程素材服务读取字节，再调用
   `POST /openapi/v2/media/upload/binary` 换成 RunningHub 自己的
   `data.download_url`。

镜像或读取失败现在会明确终止本次生成并释放预扣，不允许退回原 URL 静默继续。
上游返回空 `taskId` 时，日志和用户错误会同时带上
`errorCode / errorMessage / failedReason / status`。
