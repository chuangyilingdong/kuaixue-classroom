### HTML 工程预览

- 作品卡片继续走原版 `handleOpenBrowserUrl` 入口，不另做一套卡片逻辑。
- 单文件 HTML 使用隔离 `srcdoc` 预览。
- 带目录的工程改用一次性课程预览票据，`/kuaixue/runtime/preview/{token}/` 同时加载 index、JS、CSS、图片、字体和媒体。
- 每个预览请求重新校验当前课程权益；撤权后原预览地址失效。
- 路径拒绝目录穿越和真实路径越界；作品页运行在不带 `allow-same-origin` 的 sandbox 内，不能读取课程 RPC、宿主 Cookie 或桌面接口。
- 候选工作台实测计数器从 0 点击到 1，预览关闭后返回工作台。

### 画布素材

- 学员拖入图片、视频、音频后立即生成上传中节点，上传成功后同一节点写入 `assetUrl`、`previewUrl` 和 `fileAssetId`。
- 客户端使用原始文件流上传，不把大文件转成 Base64。
- 服务端校验登录、已购版本、画布模式、MIME、运行编号和 50 MiB 单文件上限。
- 本地参考实现按内容哈希保存对象，并将素材元数据写入 SQLite。
- 自动化测试验证了上传、鉴权拒绝、非法类型、超限、重新读取、快照保存和重新打开。
- 主站正式实现 contract 见 `docs/快学课堂_画布素材接口交付_20261123.md`。
