# 快学 VibeCoding 混合运行规格

## 决策

VibeCoding 默认使用学员电脑运行 Agent、工程文件、技能、插件和浏览器；云端工程作为兼容回退。登录、课程权益、积分、模型计费和作品同步仍由主站统一管理。

## 运行选择

- 本机已存在该课程的本地工程时，直接恢复本机工作区。
- 运行位置由系统在进入课程时自动选择，学员只看到一个统一的 VibeCoding 工作台。
- 本机运行启动失败或模型授权不可用时，系统在后台使用云端回退，不要求学员理解或操作运行环境。
- 任务执行过程中不提供运行位置切换，也不能同时写本机和云端两份工程。

## 本机运行所有者

- Electron 主进程持有本机 VibeCoding 子进程、临时运行凭据和本地工程路径。
- 本机运行器只监听 `127.0.0.1`，每个课程租约使用随机 RPC 凭据。
- 本机工程放在 `app.getPath('userData')/vibe-projects/{runId}/workspace`，不得写入安装目录。
- Agent 写入的工程文件是事实来源；关闭工作区后文件继续保留。

## 模型授权

- 本机运行不携带长期模型密钥。
- 主站通过 `POST /api/v1/course-runs/local-runtime` 下发短期、课程版本的模型网关授权。
- 授权绑定 `userId`、`courseId`、`versionId`、`runId` 和 `mode`，过期后本机生成失败。
- 所有模型请求仍由主站模型网关按版本、模型和积分规则裁决。

## 云端回退

- 现有云端运行镜像、工程目录、Browser Use 和课程预览保留。
- 本机模式不可用时，使用同一课程运行票据进入云端工作区。
- 两种模式不能同时写同一份作品。切换前必须保存并关闭当前运行器。

## 同步边界

- 第一阶段先完成本机运行、模型授权、本机持久化和云端回退。
- 正式商用前必须增加本机工程快照上传与云端恢复，用于换电脑、重装和云端回退。
- 快照至少包含工作区相对路径、文件内容或对象地址、版本、校验摘要和时间。
- 不允许用单个 `index.html` 代替整个工程目录。

当前实现：

- 公开接口由快学课程服务先校验会话、运行、权益、版本和模式。
- 模型授权与快照存储均调用主站仅限回环访问的 `/internal/kuaixue` 接口，共享密钥只存在于服务端环境变量。
- 快照采用 ZIP 中央目录校验、SHA-256 和单调 revision；同一摘要重试幂等，过期 revision 返回冲突。
- 客户端在工程目录外记录已确认的云端 revision，恢复时先解压到临时目录，再替换工作区并保留原目录备份。

## 文档能力

- ZCode 自带 Excel、Word、PPT、PDF 官方插件，生成这些文件不是课程级特殊能力，也不能据此切换运行环境。
- LibreOffice 只用于 Office 转 PDF、公式重算和部分渲染检查等特定操作。
- 本机运行时优先复用 ZCode 或随包提供的 Python 环境，保证 Excel、Word、PPT 生成能力可用。
- 不按提示词关键词判断“文档课程”，不因文件类型强制整门课程走云端。

## 验收

1. 断网但模型网关仍可达时，本机可以打开和编辑已有工程。
2. 本机 Agent 可执行文件写入、子 Agent、Browser Use 和截图。
3. 本机不保存主站长期密钥，模型授权过期后停止生成。
4. 关闭课程再打开，恢复同一本机工程。
5. 本机运行失败时不重复扣课，能够进入云端工作区。
6. 正式商用验收还要求本机工程可上传备份，并在另一台电脑恢复。
