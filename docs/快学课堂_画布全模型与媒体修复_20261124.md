# 快学课堂画布全模型与媒体修复

2026-11-24

## 已确认根因

### 视频报价与生成

生产渠道目录中，前端模型 ID 与 RunningHub/计费使用的 `providerModelKey` 不是同一个值。例如：

```text
UI / execution slug: rh-minimax-h3-multi
provider / billing key: minimax/hailuo-h3/multimodal-to-video
```

旧代码把中文显示名或前端 slug 当成计费键，因此报价返回“尚未配置积分价格”，点击生成没有后续动作。

现已将执行键和计费键拆分：RunningHub 标准 OpenAPI 使用渠道模型 ID，报价和预扣使用主站渠道的
`providerModelKey`。完整契约见
[RunningHub 模型键路由契约](./快学课堂_RunningHub模型键路由契约_20261124.md)。

- 不匹配：0

文本模型单独走 `chat-completion`，不再错误调用 RunningHub 任务接口。
